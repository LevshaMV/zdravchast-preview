# Здравчасть — временный макет

Черновой B2B-каталог. Контакты, реквизиты, характеристики конкретных товаров и сведения о наличии требуют утверждения до коммерческого запуска.

Фотографии: материалы компании, снимок КТ USDA (общественное достояние) и снимок МРТ Fatimah Bello (CC0). `index.html` — главная страница.
